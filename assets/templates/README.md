## digits_level/ — 레벨 숫자 글리프 (DigitReader, TASK-06)

덱 카드 이름 바의 흰색 레벨 숫자. 원본: img/4~6.png 이름 바
`(카드좌-2, 233+dy, 카드좌+80, 252+dy)`에서 크림 마스크(S<90, V≥170)로 분리해
수확(2026-08-09). `_N` 접미사는 같은 문자의 렌더링 변형.

| 파일 | 문자 | 비고 |
|---|---|---|
| 0.png, 0_2~0_10.png | 0 | 변형 10종(안티에일리어싱·분리 획 흡수) |
| 4.png | 4 | |
| 5.png, 5_2~5_10.png | 5 | 변형 10종 |
| 9.png | 9 | |

**잔여**: 1·2·3·6·7·8 미수확 — 픽스처에 레벨 49·50만 존재. 실기에서 다른
레벨 등장 시 '?' 판독 → partial + 증거 저장 → 수확 등록(TASK-12).

|---|---|---|---|
| win.png | 승 | img/4.png 인장 영역 (950, 112, 1045, 195) | 2026-08-09 |

**잔여**: 무(draw)·패(lose) 인장 미수확 — 실기에서 무·패 전보를 펼쳐 수확

## user/ · general/ · alliance/ — 식별 템플릿 (IdentityMatcher, 실행 시 자동 생성)

`scan` 실행 중 미등록 유저명 스트립·장수 초상·동맹명 스트립이 등장하면
IdentityMatcher가 크롭(가장자리 3px inset)을 자동 저장하고 DB
`identity_templates`에 등록한다(FR-07). 파일명 `<ns>_<순번>.png`. 이 대장에는
개별 파일을 나열하지 않는다 — 원장은 DB가 소유하며, 라벨은 `label` 명령으로
확정한다.
